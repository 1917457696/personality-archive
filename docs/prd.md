# PRD — 星象档案

## 产品目标

帮助用户把关于一个人的文字与 PDF 材料整理在本机，并从这些材料得到可追溯、试探性的人格观察。它不是心理诊断或人格测验。

## 用户与场景

个人研究者、写作者或关系观察者希望保存不同人物的公开文字、日记摘录、访谈笔记等，并在之后回看分析依据。用户自带 AI 服务商 API Key；材料只在用户主动生成报告时发送给所选服务商。

## 首版范围

- 创建、命名、删除人物档案；删除档案时级联删除材料和报告。
- 新增、编辑、删除文字材料；上传 PDF 后在浏览器逐页提取文本，显示无可提取文本提示；原始文件不保存。
- 生成前可选择材料并看到数据发送与费用提醒；生成报告后保存版本历史。来源变动后旧版本提示可能过期。
- 报告包括 MBTI、九型人格和大五人格。每项观察包含猜测、文本线索、原文引句、材料来源及 PDF 页码、替代解释和不确定性。引文需通过原文精确匹配后才能作为已验证证据展示。材料不足则明示证据不足。
- 用户选择 OpenAI、Kimi 或 Claude，并从内置模型列表选择模型。Key 仅驻留当前页面内存，支持显示/隐藏和清除；刷新即清空。
- IndexedDB 本地数据；JSON 导出及合并导入；冲突 ID 由用户决定。
- 中文 UI，桌面优先并支持手机关键流程。

## 非目标

星座解读与星座配对、账号、云同步、服务端 API、自动生成、诊断、精确人格分数、自动截断长文本、代理服务。

## 安全与隐私

页面直连服务商意味着网页脚本在运行时可访问 Key，不能视为安全的秘密存储。UI 必须说明 Key 不写入本地存储但页面运行期间可读；生成前说明完整选中材料将发送给服务商且可能产生费用。PDF 仅保留提取出的文本/页码/文件名。备份不包含 Key。不得暗中截断内容或发送未选择材料。

## 验收

档案和材料操作可持久化；PDF 页码可追溯；报告历史/过期状态可回看；精确引文验证；错误态清楚；Key 刷新后清除且从备份排除；布局支持手机；构建和模板 Sites 测试通过。

# 信息架构

## 全局导航

顶层区域为「人格档案」「单星分析」「双人配对」。顶部保留品牌与共享设置入口；仅人格档案区提供本地备份入口。

- 人格档案：人物盒子列表和新增入口；明确说明档案自动保存在当前浏览器中，清除浏览器数据前导出备份，跨设备用 JSON 导入/导出迁移。
- 单星分析：选择一个太阳星座（常说的生日星座），查看其火/土/风/水元素归类并生成关系解读。
- 双人配对：选择两人的太阳星座及可选称呼；星座选项标注四元素归类，再生成配对解读。
- 设置：服务商、模型、会话内 API Key、显示/隐藏/清除及安全说明；星座功能复用此设置。
- 导入冲突确认：逐项选择保留本地、采用导入或另存为新档案；只适用于人格档案备份。

## 档案详情

1. 人物档案标题区：改名、删除。
2. 材料区：添加文字或 PDF；编辑、删除；查看页码和文本；本次报告纳入/排除。
3. 报告动作：材料数与发送提示、生成报告。
4. 当前报告：先展示 MBTI、九型人格、大五人格三项结论速览，再展示整体观察、局限说明，以及逐项的观察、推测、原文证据和替代解释。没有可核验证据的维度显示证据不足。
5. 报告历史：时间、版本、来源变化后的过期标识。

## 关键路径

- 首次使用：创建档案 → 打开设置填 Key 并选择模型 → 档案添加文字/PDF → 选择材料 → 确认发送提示 → 生成并阅读报告。
- 维护档案：首页改名/删除；详情编辑或移除材料；报告随材料变化变为可能过期。
- 迁移数据：导出 JSON；导入时预览冲突并逐个解决。
- 单星分析：进入单星分析 → 选择十二星座之一 → 查看发送范围和费用提示 → 确认 → 展示关系倾向、需求、适合特质、磨合点、建议及娱乐性说明。
- 双人配对：进入双人配对 → 分别选择两人的星座 → 可选称呼（女/男/自定义/不指定）→ 查看发送范围和费用提示 → 确认 → 展示概览、互补、摩擦、建议及娱乐性说明。
- 星座分析缺少 Key 时打开共享设置；用户完成设置后回到原流程。取消确认不发请求。离开页面或刷新后结果消失，不出现在报告历史或备份中。

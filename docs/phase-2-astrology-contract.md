# 第二阶段契约：星座分析与双人配对

## 目标与边界

新增十二个西方太阳星座的单人关系解读和双人关系配对，沿用「星象手册」中文视觉、现有服务商设置及浏览器直连架构。星座解读属于文化/娱乐视角，不是科学评估、心理诊断或可靠预测。第一阶段的人格档案流程保持不变；本阶段不加后端、账号、星盘计算、持久化或备份能力。

## 页面与交互

- 全局导航提供「人格档案」「单星分析」「双人配对」；共享设置入口保持可用，只有档案区显示备份入口。
- 单星页选择一个星座，生成关系倾向、情感需求、适合的伴侣特质、常见磨合点、具体建议和非科学性说明。
- 配对页分别选择甲乙双方星座。每方可选称呼：女、男、自定义（1–20 字符）或不指定；默认不指定。称呼只用于称谓，不作为判断输入。结果包含关系概览、互补动态、可能摩擦、具体建议和非科学性说明，不给数字分数。
- 生成前展示确认：发送本次星座选择和已填写的可选称呼至当前服务商；请求可能产生费用；不会发送档案、材料或人格报告。确认才发请求，取消则返回表单且不发请求。
- 缺少 API Key 时打开共享设置；设置完成后回到原表单，用户仍需主动确认发送。
- 结果呈现为推测、非决定论措辞。页面内可再次生成或更换输入；切换到其他区域或刷新后清除星座结果。不得存入 IndexedDB、人格报告历史、导出备份或 URL。

## 类型与接口

- 静态配置 `ZodiacSign`：十二个西方太阳星座及中文名/稳定 ID；选择器使用此映射，不接受自由输入星座值。稳定 ID 与显示名固定为：`aries` 白羊座、`taurus` 金牛座、`gemini` 双子座、`cancer` 巨蟹座、`leo` 狮子座、`virgo` 处女座、`libra` 天秤座、`scorpio` 天蝎座、`sagittarius` 射手座、`capricorn` 摩羯座、`aquarius` 水瓶座、`pisces` 双鱼座。
- `SingleSignInput`：`sign: ZodiacSignId`。
- `CompatibilityInput`：`personA` 与 `personB` 各含 `sign: ZodiacSignId`、`label: GenderLabel`；`GenderLabel` 为 `female | male | custom | unspecified`，自定义文案仅 `custom` 可用且长度 1–20 个字符。
- `SingleSignResult`：`relationshipTendencies`、`emotionalNeeds`、`fittingPartnerTraits`、`frictionPoints`、`practicalAdvice`，以及固定的非科学性说明。
- `CompatibilityResult`：`overview`、`complementaryDynamics`、`frictionPoints`、`practicalAdvice`，以及固定的非科学性说明。列表字段需为非空字符串数组，概览需为非空字符串；任何无效结构均不展示为成功结果。
- 两种结果共用固定说明文案：「以下内容基于西方太阳星座文化，仅供娱乐与自我反思；不构成科学评估、心理诊断或可靠预测。」由 UI 展示，不依赖模型生成。
- 在 `types → config → service → runtime → ui` 增加类型、静态星座配置、星座服务、轻量运行时入口和导航/页面；复用既有 ProviderAdapter，不新增 repo 层或改 IndexedDB schema。

## 请求与数据流

1. 页面校验选择值及自定义称呼，组装仅含当前操作所需输入的请求。
2. 在请求执行前显示上述数据/费用确认；用户确认后使用当前选择的服务商、模型和仅存于内存的 Key。
3. 星座服务构建明确要求非科学、娱乐性、试探式语言及规定字段的提示，并调用现有适配器；不得读取档案仓储、材料、历史报告或备份。
4. 解析结构化 JSON 并校验必需字段、字段类型及非空约束。格式错误显示可重试错误，不把原始响应当报告展示。
5. 结果只置于 UI 会话状态；不新增持久化调用，不改变第一阶段导入/导出格式。

## 状态与错误

- 空闲：显示输入表单和生成操作；输入无效时阻止提交并就地说明。
- 缺少 Key：打开共享设置；用户取消后回到表单，无网络请求。
- 确认发送：显示服务商、数据范围与费用提示；取消不发请求。
- 生成中：禁用重复提交并提供可理解的忙碌反馈。
- 成功：展示校验通过的结构化结果和非科学性说明；新请求替换当前结果。
- 失败：区分网络/CORS、HTTP 限流/额度/鉴权、响应格式错误；保留输入，说明重试或检查服务商设置的下一步，不静默重发。
- 切换页面或刷新：清除结果及错误状态；不影响 Key 的既有会话生命周期，刷新仍由第一阶段行为清空 Key。

## 验收

- 桌面与手机均可通过导航完成单星与配对流程，且保持星象手册风格。
- 校验十二星座映射、双方独立选择、四种称呼及自定义长度边界；称呼不进入兼容性推理规则。
- 单星/配对结果字段完整、文案包含非科学性说明且没有匹配分数；非法 JSON/缺字段不能呈现为成功。
- 覆盖缺 Key、取消发送、网络失败、HTTP 错误/限流/额度、格式错误与重试；模拟请求断言仅含本次星座输入和可选称呼，不含人物档案材料。
- 刷新、切换区域后星座结果不恢复；检查 IndexedDB、报告历史和导出内容均无星座结果。
- 构建、TypeScript、单元测试、Sites 测试及桌面/手机浏览器验收通过；不执行真实服务商请求或产生真实费用。

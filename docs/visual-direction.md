# 视觉方向 — 星象手册

## 意图

以一册安静的星象手记作为外层气质，以档案索引和编辑式报告承载实际工作。星象元素只构成氛围，不参与人格推断。

## 视觉语言

- 深墨蓝、夜空紫作为导航与背景；暖纸白作为材料阅读面；黄铜色只用于小面积强调与状态标记。
- 标题使用有书卷气的中文衬线/系统衬线，正文保持高可读的无衬线；数字、时间、页码使用清晰等宽或系统字形。
- 人物档案呈现为一排可横向浏览的档案牌；盒子更接近资料匣标签，而非游戏卡片。手机改为顺序堆叠。
- 报告以编辑式层级呈现：观察结论、原文引句、出处、替代解释清晰分开。引用可点击回到材料。
- 可用轻微星点、轨道线或罗盘符号作为 CSS/SVG 装饰；避免装饰影响内容辨读。
- 视觉精修采用编辑式星象手记：更明确的留白节奏、细纸纹色阶、档案牌层次和细线星图，营造艺术感但不牺牲材料与结论的易读性。避免过度圆角、厚重阴影和泛用仪表盘质感。
- API 设置中的隐私说明面向普通用户，使用“会发送什么、可能产生什么费用、如何更稳妥使用”的直白表达；不在产品界面解释 CORS 等实现术语。
- 交互响应克制，遵循 reduced-motion；键盘焦点、对比度、触控目标清楚。

## 设计原则

1. 先看到档案与证据，再看到星象氛围。
2. 不确定性是报告语气的一部分，而非免责声明脚注。
3. 私密与发送边界在关键时刻可见。
4. 桌面保留索引感，移动优先保证档案、材料、报告的顺序操作。

## 设计验证

原始设计方向为用户确认的文字描述，而非可供逐像素比对的 mockup。实现后应记录真实浏览器截图与检查结果；若无源图像可比对，应明确标记视觉对照限制。
